# Лабораторная работа №5. DOM и взаимодействие с элементами страницы
 
**Вариант 17.** Тема «Языковой энтузиаст и переводчик» — словарь слов с переводами.
 
## Цель
 
Научиться манипулировать DOM-деревом, находить элементы, изменять содержимое и стили, а также сохранять состояние страницы между перезагрузками через `localStorage`.
 
## Задание по варианту
 
- Контент: строки таблицы (слово, перевод, кнопка «Удалить»).
- Кнопка «Добавить слово» создаёт строку в таблице.
- Кнопка «Очистить словарь» удаляет все строки.
- Переключение темы (светлая / тёмная).
- Скрытие и показ словаря.
- Обработка ошибок.
- Сохранение состояния в `localStorage` и его восстановление при загрузке.
## Структура проекта
 
```
├── index.html — разметка страницы (секция «Словарь» — #dictionary)
├── style.css — стили, CSS-переменные светлой и тёмной темы
├── script.js — логика работы с DOM и localStorage
└── README.md
```
 
## Запуск
 
1. Скачать или клонировать репозиторий.
2. Открыть `index.html` в браузере (Chrome, Firefox, Edge).
3. Ввести имя во всплывающем окне `prompt` (можно оставить пустым — будет «Гость»).
4. Перейти к разделу «Словарь» через меню навигации.
Сервер не требуется, внешних зависимостей нет.
 
## Реализованные функции
 
### 1. Поиск элементов
 
| Метод | Где используется |
|---|---|
| `getElementById` | обёртка `getEl(id)` — поиск таблицы, полей ввода, кнопок, блока ошибок |
| `querySelector` | обёртка `getFirst(selector)` — `#theme-toggle`, `#word-form`, `main h2` |
| `querySelectorAll` | обёртка `getAll(selector)` — все карточки языков `.lang-card` |
 
Каждая обёртка проверяет, найден ли элемент, и выводит предупреждение в консоль, если его нет.
 
### 2. Манипуляции с DOM
 
- **Изменение текста** — `textContent` (статистика, подписи кнопок, сообщения об ошибках).
- **Изменение атрибутов** — `setAttribute('data-index', ...)` для кнопок «Удалить» и карточек языков; `hidden` у блока «Отличный темп».
- **Изменение классов** — `classList.add / remove / toggle` (тема `dark-theme`, скрытие `dictionary-hidden`).
- **Добавление элементов** — `createElement` + `appendChild` для строк таблицы (`<tr>`, `<td>`, `<button>`) и диаграммы прогресса.
- **Удаление элементов** — перерисовка `tbody` после удаления слова из массива (`splice`) или полной очистки словаря.
### 3. Словарь слов
 
- **Добавление слова** — форма `#word-form`, функция `addWord(word, translation)`. Новая строка содержит слово, перевод и кнопку «Удалить». После успешного добавления поля очищаются, фокус возвращается в поле «Слово».
- **Удаление слова** — кнопка «Удалить» в строке, функция `deleteWord(index)`.
- **Очистка словаря** — кнопка «Очистить словарь», функция `clearDictionary()` с подтверждением через `confirm`.
- **Пустой словарь** — при отсутствии слов выводится сообщение «Словарь пуст. Добавьте первое слово.».
### 4. Переключение темы
 
Кнопка в шапке сайта переключает класс `dark-theme` у `<body>`. Цвета заданы CSS-переменными в `:root` и переопределяются в `body.dark-theme`. Текст кнопки меняется: «🌙 Тёмная тема» / «☀️ Светлая тема».
 
### 5. Скрытие / показ блока
 
Кнопка «Скрыть словарь» / «Показать словарь» переключает класс `dictionary-hidden` у блока `#dictionary-content` (форма, таблица, кнопка очистки).
 
### 6. Обработка ошибок
 
| Ситуация | Реакция |
|---|---|
| Элемент не найден в DOM | предупреждение в консоли, код не падает |
| Пустое слово или перевод (в т. ч. только пробелы) | сообщение «Ошибка: введите непустые значения.» |
| Повтор слова (без учёта регистра) | сообщение «Ошибка: слово "…" уже есть в словаре.» |
| Неверный индекс при удалении | сообщение «Ошибка: неверный индекс слова.» |
| Очистка пустого словаря | сообщение «Словарь уже пуст.» |
| `localStorage` недоступен | `try/catch` в `safeGetStorage` / `safeSetStorage`, предупреждение в консоли |
| Повреждённые данные в `localStorage` | `try/catch` вокруг `JSON.parse`, словарь сбрасывается в пустой массив |
 
Сообщения об ошибках выводятся в блок `#dictionary-error` (`role="alert"`) и автоматически исчезают через 3 секунды.
 
### 7. Сохранение состояния в localStorage
 
| Ключ | Что хранится | Когда сохраняется |
|---|---|---|
| `vadim_theme` | `light` / `dark` | при переключении темы |
| `vadim_dictionary` | массив `{ word, translation }` в JSON | при добавлении, удалении, очистке |
| `vadim_dict_visible` | `visible` / `hidden` | при скрытии / показе словаря |
 
При загрузке страницы функции `loadTheme()`, `loadDictionary()` и `loadDictionaryVisibility()` восстанавливают сохранённое состояние.
 
## Проверка работы
 
1. Добавить несколько слов — строки появляются в таблице.
2. Попробовать добавить пустое слово или уже существующее — появляется сообщение об ошибке.
3. Удалить одно слово кнопкой «Удалить».
4. Переключить тему на тёмную и скрыть словарь.
5. Перезагрузить страницу (F5) — тема, слова и состояние видимости словаря сохранились.
6. Нажать «Очистить словарь» и подтвердить — таблица пуста, выводится сообщение о пустом словаре.
7. Открыть DevTools → Application → Local Storage и убедиться, что ключи `vadim_*` обновляются.
