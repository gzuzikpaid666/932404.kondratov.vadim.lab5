Массив из 7 чисел — количество новых слов, выученных за каждый день:
const wordsPerDay = [12, 55, 8, 63, 30, 5, 72];

Что реализовано
Поиск элементов
`getElementById` — поиск по id (например, `document.getElementById('dictionary-body')`).
`querySelector` — поиск по CSS-селектору, возвращает первый элемент (например, `document.querySelector('#theme-toggle')`).
`querySelectorAll` — поиск по CSS-селектору, возвращает NodeList всех подходящих элементов (например, `document.querySelectorAll('.lang-card')`).
Все три метода обёрнуты в функции `getEl`, `getFirst`, `getAll` с проверкой на существование элемента и выводом предупреждения в консоль, если элемент не найден.
Манипуляции с DOM
`createElement` — создание элемента с заданным тегом, классом и текстом.
`appendChild` — добавление созданного элемента в DOM.
`textContent` — изменение текстового содержимого элемента.
`className` — установка класса элемента.
`setAttribute` — установка атрибута (например, `data-index` для кнопок удаления).
`classList.toggle` — переключение класса (используется для скрытия/показа блока словаря).
`remove` / `splice` — удаление элементов из DOM и из массива данных.
Переключение темы
Кнопка `#theme-toggle` в шапке страницы переключает класс `dark-theme` на элементе `body`.
CSS-переменные (`--main-color`, `--bg-light`, `--text-dark` и др.) автоматически меняют цвета всех элементов при добавлении класса.
Выбранная тема сохраняется в `localStorage` под ключом `vadim_theme` и восстанавливается при загрузке страницы.
Словарь слов (Вариант 17)
Форма `#word-form` с полями «Слово» и «Перевод» и кнопкой «Добавить слово».
При отправке формы создаётся новая строка в таблице `#dictionary-body` с тремя ячейками: слово, перевод, кнопка «Удалить».
Кнопка «Удалить» удаляет конкретную запись по индексу.
Кнопка «Очистить словарь» удаляет все записи с подтверждением через `confirm()`.
Кнопка «Скрыть словарь» скрывает/показывает блок `#dictionary-content` переключением класса `dictionary-hidden`.
Состояние видимости блока сохраняется в `localStorage`.
Обработка ошибок и валидация
Проверка существования DOM-элементов перед обращением к ним (во всех обёртках `getEl`, `getFirst`, `getAll`).
Валидация полей формы: запрет пустых значений, проверка типа данных, проверка на дубликаты (регистронезависимая).
Безопасная работа с `localStorage` через функции `safeGetStorage` и `safeSetStorage` с блоками `try...catch`.
Вывод сообщений об ошибках в элемент `#dictionary-error` с автоматическим скрытием через 3 секунды.
Сохранение состояния в localStorage
Тема (`vadim_theme`) — сохраняется при каждом переключении, восстанавливается при загрузке.
Словарь (`vadim_dictionary`) — массив объектов `{word, translation}` сохраняется в формате JSON при каждом добавлении/удалении, восстанавливается при загрузке.
Видимость блока словаря (`vadim_dict_visible`) — сохраняется при скрытии/показе, восстанавливается при загрузке.

Пример работы со словарём:
Пользователь вводит слово "hello" и перевод "привет".
В таблице появляется строка: | hello | привет | [Удалить] |
Данные сохраняются в localStorage.
При перезагрузке страницы словарь восстанавливается.
Пользователь нажимает «Удалить» — строка исчезает, данные обновляются в localStorage.
Дополнительно: вывод на страницу
Кроме обязательных `prompt`, `alert` и `console.log`, результат показывается на самой странице в секции «Мой прогресс в изучении слов»:
приветствие по введённому имени;
четыре карточки: всего слов, дни с высоким прогрессом, дни с малым прогрессом (с процентом), среднее за день;
плашка «Отличный темп изучения языка!», если среднее больше 30;
диаграмма «Слов по дням» — полоса на каждый день с пометкой «высокий», «средний» или «малый» (цвет дублируется текстом);
в консоли данные выводятся таблицей через `console.table`.
Секция «Словарь слов с переводами»:
форма добавления слова и перевода;
таблица с колонками «Слово», «Перевод», «Действие»;
кнопка «Скрыть словарь» для сворачивания блока;
кнопка «Очистить словарь» для полного удаления записей;
сообщение «Словарь пуст», если записей нет;
блок для вывода ошибок с автоматическим скрытием.
Скрипт запускается после загрузки страницы (`load`), поэтому страница успевает отрисоваться до появления окна с вопросом об имени. Блок адаптивный: карточки статистики идут в 4, 2 и 1 колонку на десктопе, планшете и мобильном. Форма словаря адаптируется под ширину экрана.
